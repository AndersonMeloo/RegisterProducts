# Cadastro de Produtos

## Tecnologias Utilizadas

### Backend
- NestJS
- Prisma ORM
- PostgreSQL
- TypeScript

### Frontend
- Next.js
- Tailwind CSS
- TypeScript

# Backend
Funcionalidades
- Cadastro de produtos
- Listagem de produtos
- Atualização de produtos
- Remoção de produtos

## Crie um arquivo .env dentro da pasta backend
```
DATABASE_URL=""
```

## Rodando o Backend
```
cd backend
npm install
npx prisma migrate dev
npm run start
```

# Backend
Funcionalidades
- Consumo da API de produtos
- Listagem dos produtos cadastrados
- Interface estilizada com Tailwind CSS

## Rodando o Frontend
```
cd frontend
npm install
npm run dev
```
